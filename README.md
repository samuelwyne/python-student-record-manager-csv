# Python Student Record Manager (CSV)

## Description

This project is a Python application that manages student records using CSV files. It allows users to add, view, and search student information while learning how to work with structured data.

## Features

- Add student records
- Save records to a CSV file
- Read records from a CSV file
- Search for a student by name
- Display all student records

## Technologies Used

- Python 3
- CSV Module

## Concepts Practiced

- CSV File Handling
- Loops
- Functions
- User Input
- File Operations

## Future Improvements

- Update student records
- Delete student records
- Sort students by marks
- Generate summary reports
